Direct join (two tabs, same session ID):
  1. Open in two tabs, paste same API Key + Session ID
  2. Click Connect & Join in both — call starts automatically
Ringing flow (caller/callee):
  1. Tab 1 = Caller, Tab 2 = Callee — use different User IDs
  2. Both click Connect (no session ID needed for callee)
  3. Caller enters callee's User ID in Session ID field and clicks Ring Callee
  4. Tab 2 gets an incoming call popup — Accept or Reject
