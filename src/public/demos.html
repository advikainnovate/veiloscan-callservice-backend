Communication Platform

Internal demo — shows live call and chat flows using the platform API.

Before you start

Both demos require an API key to authenticate with the platform. Use an existing key or create one:

  1. POST /api/v1/organizations with { "name": "Demo Org" } — save the id
  2. POST /api/v1/organizations/:id/api-keys with { "name": "Demo Key" } — save the apiKey
  3. Paste that key into the API Key field on the demo page

CALL Call Demo

Two-peer WebRTC voice call using the Call SDK. Open in two browser tabs, enter the same API key and session ID, click Connect in both — then the call starts automatically when both peers join.

CHAT Chat Demo

Real-time messaging using the Chat SDK. Open in two browser tabs, enter the same API key and room ID, click Join in both — then send messages between the tabs.
