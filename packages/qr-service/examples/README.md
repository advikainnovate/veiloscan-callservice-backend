# Examples

This directory contains examples of how to use the QR Service in different scenarios.

## Files

- **basic-integration.js** - Simple Express app setup
- **custom-adapter.js** - Example of implementing a custom database adapter
- **error-handling.js** - Error handling patterns
- **direct-service-usage.js** - Using the service without Express

See [../docs/INTEGRATION.md](../docs/INTEGRATION.md) for full integration guide.
